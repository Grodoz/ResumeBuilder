# ResumeBuilder
First prototype of my first app, Resume Builder

This is the first prototype of my app Resume Builder.  This app is designed to address a major pain point for people who are trying to find a job, their resumes and how to get them past the ATS (Applicant Tracking System) being used by major corporations.  This prototype has several features:
1) Resume scoring by using a similar algorithm to current ATS systems.  This score is shown using a graphical interface using a Gauge and bar chart showing each element of a resume (STAR, Formatting, Verb usage).
2) AI framework using Google Gemini AI.  The AI will act as a coach to help people prepare for interviews using both a chat interface and voice recording.
3) Recommendations to enhance the score of resumes against the ATS system and what to change in the resume to get noticed by recruiters and hiring managers.
4) Cover letter generator to create cover letters.
5) Local storage of resume and cover letters in both .pdf and .docx (Microsoft Word) formats.
6) Cloud storage of resumes using Google Docs.

Currently, this app is geared towards tech professionals, however, in the future, it will have the ability to help with resumes in all of the fields that are using an ATS system.  Someday, I want to publish this app on the Google Store.  I welcome any feedback on this app and you can do this by e-mailing me at rbroyles1k@gmail.com.  This app was created using Android Studio Rabbit edition.  The minimum SDK for this app is Android Nougat (7.1).  This app used the following technologies: Android SDK, Coroutines (Kotlin), Room database, Jetpack Compose, Gemini AI API, Android voice recording, Retrofit, OkHttp, Moshi, JUnit, SQLite, and Mockito for testing.  The next prototype will incorporate Firebase.
